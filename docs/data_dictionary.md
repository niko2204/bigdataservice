# 데이터 사전

| 열 | 형식 | 설명 |
|---|---|---|
| 행정동명 | 문자열 | 분석 단위 |
| 위도·경도 | 실수 | 행정동 대표 좌표 |
| 총인구 | 정수 | 주민등록 인구 |
| 20대·30대인구 | 정수 | 잠재고객 예시 |
| 유동인구 | 정수 | 교육용 생활인구 지표 |
| 업종별 점포수 | 정수 | 경쟁도 측정값 |
| 주차장수 | 정수 | 접근성 대리변수 |
| 평균거래가 | 실수 | 비용 대리변수 |
| 적합도 | 0~100 | 정규화 가중합 점수 |

실제 프로젝트에서는 출처, 기준일, 공간 단위, 결측률, 변환 방법을 열별로 추가 기록한다.
