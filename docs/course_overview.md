# 교과목 개요

- 교과목명: 빅데이터서비스(Big Data Service)
- 대상: 컴퓨터학부 4학년
- 운영: 프로젝트 기반 학습, 팀당 3~4명 권장
- 프로젝트: 지역 생활인구·상권 빅데이터 기반 창업 입지 추천 서비스

## 학습성과

학생은 공공데이터 API를 수집·정제·통합하고, 데이터 기반 질문을 시각화하며, 설명 가능한 추천 모델과 웹 서비스를 구현할 수 있다. 또한 GitHub로 협업하고 데이터 출처·한계·윤리를 문서화할 수 있다.

## 권장 평가

- Course 실습·퀴즈 15%
- 데이터 수집·전처리 과제 15%
- 중간 점검 20%
- 최종 서비스 30%
- 보고서·발표 15%
- 동료평가 5%
