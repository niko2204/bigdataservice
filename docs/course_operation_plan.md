# 프로젝트 중심 운영안

Course 번호는 수업 주차가 아니다. 팀 진행 상황에 따라 필요한 Course를 선택하여 짧게 강의하고 프로젝트 시간을 배정한다.

| 단계 | 권장 기간 | 사용하는 Course | 점검 결과 |
|---|---:|---|---|
| 시작 | 1~2주 | 01~02 | 문제 정의, 저장소, 기초 분석 |
| 데이터 | 3~5주 | 03~04 | 출처, 수집 코드, 통합 데이터 |
| 분석 | 6~8주 | 05~06 | EDA, 지도, 중간발표 |
| 모델 | 9~10주 | 07~08 | 점수 모델, DB |
| 서비스 | 11~13주 | 09 | 작동하는 프로토타입 |
| 완성 | 14~15주 | 10 | 테스트, 최종발표, 회고 |

매 수업은 15분 진행 공유, 20~30분 미니 강의, 팀 개발, 마지막 10분 회고로 운영할 수 있다.
