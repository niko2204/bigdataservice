# 데이터 안내

`sample/` 데이터는 수업 실행을 위해 구성한 **합성 교육용 데이터**입니다. 실제 통계가 아닙니다.

## 실제 데이터 출처

1. 소상공인시장진흥공단 상가(상권)정보 API: https://www.data.go.kr/data/15012005/openapi.do
2. 행정안전부 성·연령별 주민등록 인구 API: https://www.data.go.kr/data/15108074/openapi.do
3. 행정안전부 주민등록 인구·세대 API: https://www.data.go.kr/data/15108071/openapi.do
4. 행정안전부 지역별 인구이동 API: https://www.data.go.kr/data/15108093/openapi.do
5. 국토교통부 상업·업무용 부동산 실거래가 API: https://www.data.go.kr/data/15126463/openapi.do
6. 전국 주요 상권 표준데이터: https://www.data.go.kr/data/15029180/standard.do
7. SGIS 통계지리정보서비스: https://sgis.kostat.go.kr/

원본 파일은 `raw/`, 정제 중간 파일은 `interim/`, 모델 입력·서비스용 파일은 `processed/`에 둡니다. 개인정보나 API 인증키를 커밋하지 마세요.
