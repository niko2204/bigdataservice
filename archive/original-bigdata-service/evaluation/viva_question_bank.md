# 데이터 분석 구두 확인 질문은행

교수자는 학생별로 3~5개를 무작위 선택한다.

1. 평균 대신 중앙값을 사용하면 결과가 어떻게 달라지는가?
2. `ddof=0`과 `ddof=1`의 차이를 현재 데이터로 보여라.
3. 결측값을 평균으로 대체할 때 분산은 어떻게 변하는가?
4. IQR 임계값을 1.5에서 3.0으로 바꾸고 제거 건수를 설명하라.
5. 상관계수가 높아도 인과관계라고 할 수 없는 이유는?
6. p값과 효과크기는 각각 무엇을 말하는가?
7. 학습·평가 데이터를 나누지 않으면 어떤 문제가 생기는가?
8. MAE와 RMSE가 이상값에 다르게 반응하는 이유는?
9. K-means 전에 표준화하지 않으면 어떤 변수가 지배하는가?
10. 군집 번호 0, 1, 2 자체에 순서 의미가 있는가?
11. 추천 가중치를 10% 바꾸었을 때 순위가 안정적인지 확인하라.
12. 현재 결과를 실제 정책·창업 결정에 사용하기 어려운 이유를 2개 말하라.
