# Course 02. Python 데이터 분석

CSV를 pandas DataFrame으로 읽고 열 선택, 조건 검색, 그룹 집계, 결측값 확인을 수행한다. `data/sample/location_features.csv`를 사용해 행정동별 유동인구와 점포당 인구를 계산한다.

## 필수 이론·실습

- Lab 00: 합, 평균, 편차, 벡터 거리의 손계산과 NumPy 검증
- Lab 02: 표본분산, 표준편차, z점수와 업종별 기술통계
- 학생은 계산 공식을 코드로 직접 구현한 뒤 라이브러리 결과와 비교한다.

`lecture_note.ipynb`의 예제 셀을 먼저 실행한 뒤 Lab 00과 Lab 02의 TODO를 수행한다. 코드를 복사하는 데 그치지 말고 중간 결과의 행 수와 단위를 확인한다.
