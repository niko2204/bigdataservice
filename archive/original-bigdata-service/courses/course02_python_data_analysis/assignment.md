# 실습 과제: pandas와 기술통계

## 수행

1. 지역·점포 데이터의 관측 단위와 열별 단위를 작성한다.
2. 품질 프로파일을 만들고 행정동·점포 식별자 유일성을 검증한다.
3. 유동인구 상위 5개와 카페당 20대 인구 상위 5개를 계산한다.
4. 표본분산을 라이브러리 없이 계산하고 pandas 결과와 비교한다.
5. 결과 차이를 관찰·해석·한계로 구분해 작성한다.

Restart & Run All을 통과한 Notebook과 1쪽 해석을 제출한다. 계산 35%, 검증 20%, 수학 설명 20%, 해석 20%, 재현성 5%다.
