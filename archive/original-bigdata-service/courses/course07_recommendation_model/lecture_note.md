## 2. 추천 문제 정의

입지 추천은 정답 지역이 명확하지 않은 다기준 의사결정 문제다. 먼저 다음을 정의한다.

- 대안: 비교할 행정동
- 기준: 잠재고객, 유동인구, 경쟁, 접근성, 비용
- 방향: 클수록 좋은지, 작을수록 좋은지
- 가중치: 사용자 선호
- 출력: 점수, 순위, 근거와 불확실성

## 3. 정규화

단위가 다른 값을 그대로 더하면 값의 규모가 큰 변수가 점수를 지배한다. Min-Max 정규화는 다음과 같다.

$$z_i=\frac{x_i-x_{min}}{x_{max}-x_{min}}$$

비용이나 경쟁처럼 작을수록 좋은 기준은 `1-z`로 방향을 통일할 수 있다.

```python
def minmax(series):
    span = series.max() - series.min()
    if span == 0:
        return pd.Series(0.5, index=series.index)
    return (series - series.min()) / span

score = (
    .25 * minmax(df["20대인구"])
    + .25 * minmax(df["유동인구"])
    + .20 * (1 - minmax(df["카페수"]))
    + .15 * minmax(df["주차장수"])
    + .15 * (1 - minmax(df["평균거래가"]))
)
```

Min-Max는 새 최댓값·이상값에 민감하다. z점수, 순위 기반 점수, 강건 스케일링과 비교한다.

## 4. 가중합과 가중치

$$S_i=\sum_{j=1}^{p}w_j z_{ij},\qquad w_j\ge0,\quad\sum_jw_j=1$$

가중치는 객관적 진실이 아니라 선호 또는 정책 선택이다. 가중치 출처를 기록하고 사용자가 바꿀 수 있게 한다.

```python
weights = {"잠재고객": .25, "유동인구": .25, "경쟁완화": .20, "접근성": .15, "비용효율": .15}
assert abs(sum(weights.values()) - 1) < 1e-9
```

## 5. 민감도 분석

기본 가중치만 보고하지 말고 각 가중치를 ±10~20% 바꾸어 상위 순위가 얼마나 유지되는지 확인한다.

```python
scenarios = {
    "균형": [.25, .25, .20, .15, .15],
    "유동중심": [.15, .45, .15, .10, .15],
    "저비용": [.15, .15, .15, .10, .45],
}
```

시나리오마다 순위가 크게 바뀐다면 하나의 추천 대신 조건별 후보를 제시한다.

## 6. 선형회귀

회귀는 관측된 특성으로 연속값을 예측한다.

$$\hat{y}=\beta_0+\beta_1x_1+\cdots+\beta_px_p$$

최소제곱은 잔차제곱합을 최소화한다.

$$SSE=\sum_i(y_i-\hat{y}_i)^2$$

데이터를 학습·테스트로 분리하고 MAE, RMSE, R²를 함께 본다.

$$MAE=\frac1n\sum|y_i-\hat y_i|,\quad RMSE=\sqrt{\frac1n\sum(y_i-\hat y_i)^2}$$

RMSE는 큰 오차에 더 큰 벌점을 준다. R²가 높아도 데이터 누수, 표본 편향, 외삽 문제가 있으면 실제 성능을 보장하지 않는다.

## 7. K-means 군집

K-means는 다음 목적함수를 최소화한다.

$$J=\sum_{k=1}^{K}\sum_{x_i\in C_k}\|x_i-\mu_k\|^2$$

거리 기반이므로 표준화가 필수적이다. k 선택에는 inertia의 elbow와 silhouette를 함께 사용한다. 군집 번호는 순서나 품질을 뜻하지 않으며 군집 프로필을 보고 이름을 붙인다.

## 8. PCA

PCA는 분산을 최대한 보존하는 직교 축으로 데이터를 투영한다. 2차원 시각화에는 유용하지만 정보가 손실된다. 설명분산비율과 변수 적재량을 확인해야 한다.

## 9. 검증과 설명

추천 결과에는 다음을 함께 보여준다.
