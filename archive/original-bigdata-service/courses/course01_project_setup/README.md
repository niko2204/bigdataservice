# Course 01. 프로젝트 이해와 환경 구축

[![Open Lecture Note in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/niko2204/bigdataservice/blob/main/courses/course01_project_setup/lecture_note.ipynb)

## 목표
빅데이터 서비스를 정의하고 팀의 분석 문제, 사용자, 성공 기준을 구체화한다.

## 실습
저장소를 복제하고 가상환경을 만든 뒤 Streamlit 샘플 서비스를 실행한다. `프로젝트 제안서`에 사용자, 문제, 입력 데이터, 출력 화면을 작성한다.

## 완료 기준
서비스를 로컬에서 실행하고 팀원 모두가 첫 커밋 또는 코드 리뷰를 남긴다.

## 학습 순서

1. `lecture_note.ipynb`를 열고 서비스와 분석의 차이를 정리한다.
2. `slides.md`로 핵심 개념을 복습한다.
3. 저장소를 실행하고 화면별 데이터 흐름을 추적한다.
4. `assignment.md`와 프로젝트 제안서 양식을 작성한다.
5. `quiz.md`에 말로 답할 수 있는지 확인한다.
