# 확인 문제 해설

1. 완전성은 임대료 결측, 유일성은 같은 점포번호 반복, 유효성은 음수 인구 또는 국내 범위 밖 좌표가 예다.
2. 같은 대표값을 반복 삽입하여 변동이 작아지고 공분산·상관구조가 달라질 수 있다.
3. 이상값은 실제 중요한 관측일 수 있다. 원인, 단위, 원자료와 분석 영향을 확인한 후 처리한다.
4. left join은 왼쪽 모든 행을 유지하고 inner join은 양쪽 키가 일치한 행만 유지한다.
5. 같은 이름이 다른 시군구에 있거나 행정동·법정동·기준시점이 다르면 오병합 또는 누락이 생긴다.
6. validate는 기대한 1:1·1:N 관계 위반을 찾고 indicator는 일치·미일치 출처를 표시한다.
