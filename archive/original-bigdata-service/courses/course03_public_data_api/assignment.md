# 실습 과제: 재현 가능한 API 수집기

## 수행

1. 공식 API 한 개를 선정하고 활용가이드의 필드 5개를 정리한다.
2. 샘플 10건으로 상태·본문 구조를 확인한 뒤 페이지네이션으로 100건 이상 수집한다.
3. timeout과 429·500대 오류의 제한적 재시도를 구현한다.
4. 원본 JSON, 정제 CSV와 수집 메타데이터를 분리한다.
5. 원본·정제 건수, 식별자 중복, 결측과 좌표 범위를 검증한다.

## 제출·평가

키를 제외한 코드, 작은 원본 예시, 메타데이터와 실행 로그를 제출한다. 수집 완전성 30%, 오류 처리 25%, 품질 검증 25%, 보안·문서 20%다.
