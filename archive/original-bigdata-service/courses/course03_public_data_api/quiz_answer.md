# 확인 문제 해설

1. Endpoint는 기능 주소, parameter는 조회 범위, 인증은 호출 권한, response는 상태와 결과 본문이다.
2. 본문 안에 업무 오류 코드나 빈 결과가 포함될 수 있어 상태 코드와 본문을 모두 검사해야 한다.
3. 누적 건수가 전체 건수 이상이거나 현재 페이지가 비었을 때 종료할 수 있으며 최대 페이지 안전장치도 둔다.
4. timeout은 제한된 횟수와 backoff로 재시도하고, 429는 호출 제한을 확인해 대기 간격을 늘린다.
5. 기준일은 데이터가 나타내는 시점, 수집일은 파일을 가져온 시점이다.
6. 파싱 오류를 재검증하고 전처리를 재현하며 원자료와 변환 결과 차이를 추적하기 위해서다.
