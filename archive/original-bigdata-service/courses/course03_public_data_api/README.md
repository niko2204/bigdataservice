# Course 03. 공공데이터 API

[![Open Lecture Note in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/niko2204/bigdataservice/blob/main/courses/course03_public_data_api/lecture_note.ipynb)

REST 요청, 파라미터, JSON·XML 응답, 페이지네이션, 오류 처리와 인증키 보안을 학습한다. `src/data_collection/api_client.py`에서 반경 내 상가 조회를 실행한다.

`lecture_note.ipynb`의 요청·응답 예제를 학습한 뒤 10건 호출, 페이지네이션, 재시도, 원본 보존 순서로 확장한다. 인증키가 없다면 프로젝트 API Notebook의 예제 응답 구조를 먼저 사용한다.
