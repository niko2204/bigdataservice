# 프로젝트 가이드

## 필수 기능

1. 출처가 명확한 데이터 3종 이상 수집
2. 재현 가능한 전처리 파이프라인
3. 분석 질문 5개와 시각화 5개 이상
4. 지도 시각화 1개 이상
5. 설명 가능한 입지 추천 점수
6. Streamlit 다중 페이지 서비스
7. 결과 다운로드와 데이터 한계 안내

## 팀 역할 예시

- 데이터 엔지니어: 수집·정제·DB
- 데이터 분석가: EDA·지표·검증
- 모델 개발자: 점수·군집·평가
- 서비스 개발자: Streamlit·지도·통합

역할은 책임 구분이며 모든 팀원은 코드 리뷰와 발표에 참여한다.
