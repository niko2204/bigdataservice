# 학생 자율학습 가이드

## 1. 자료의 역할

각 Course 폴더에는 다음 자료가 있다.

- `README.md`: 학습목표와 권장 순서
- `lecture_note.ipynb`: 개념, 수식과 직접 실행할 Python 예제 셀
- `lecture_note.md`: GitHub 열람과 Notebook 재생성을 위한 동일 내용 원본
- `slides.md`: 수업 중 핵심 요약
- `assignment.md`: 제출 과제와 평가기준
- `quiz.md`: 스스로 답할 확인 문제
- `quiz_answer.md`: 답을 작성한 뒤 확인할 해설

Notebook에는 완성 예제, 따라하기, 독립 연습과 자가점검이 순서대로 들어 있다.

## 3. 한 Course를 공부하는 방법

1. README에서 목표와 선수지식을 확인한다.
2. lecture_note.ipynb를 열고 수식을 작은 숫자로 손계산한다.
3. 완성 코드를 그대로 실행하기 전에 결과를 예상한다.
4. 코드 한 줄 또는 파라미터를 바꾸고 결과 차이를 기록한다.
5. Notebook TODO를 본인 학번 데이터로 완성한다.
6. 그래프 아래에 관찰·해석·한계를 구분해 쓴다.
7. 퀴즈에 답한 뒤 해설과 비교하고 틀린 이유를 기록한다.
8. 과제를 수행하고 Restart & Run All로 최종 확인한다.

## 4. 코드가 작동하지 않을 때

다음 순서로 확인한다.

1. 오류 메시지의 마지막 줄에서 예외 종류와 원인을 읽는다.
2. 현재 작업 폴더와 파일 존재 여부를 확인한다.
3. shape, columns, dtypes와 head를 다시 출력한다.
4. 오류가 난 긴 코드를 작은 셀로 나눈다.
5. 직전 정상 중간값과 현재 값을 비교한다.
6. 문서 또는 외부 도구의 제안을 적용하기 전에 입력·출력을 예상한다.
7. 수정 후 전체 Notebook을 처음부터 다시 실행한다.

## 5. 외부 AI 도구 사용 원칙

외부 도구의 사용을 숨기기보다 다음을 제출물에 기록한다.

- 어떤 질문에 사용했는가?
- 제안 코드 중 무엇을 채택·수정·거부했는가?
- 결과를 어떤 계산, 문서 또는 테스트로 검증했는가?
- 다른 조건에서도 작동하는지 어떻게 확인했는가?

평가는 코드 길이보다 수학적 의미, 데이터 처리 선택, 검증, 해석과 현장 수정 능력을 중심으로 한다.

## 6. 제출 전 공통 체크리스트

- [ ] 학번과 분석 질문이 명확하다.
- [ ] 원본·정제·분석 데이터를 구분했다.
- [ ] 표본 수, 단위, 기준일과 출처가 있다.
- [ ] 중간 결과와 검증 assert가 있다.
- [ ] 처리 대안 또는 기준모델을 비교했다.
- [ ] 관찰·해석·한계를 구분했다.
- [ ] Restart & Run All을 통과했다.
- [ ] 임의의 셀을 말로 설명하고 조건을 바꾸어 수정할 수 있다.
