# 확인 문제 해설

1. 분석은 특정 질문에 한 번 답할 수 있지만 서비스는 입력 변화에 따라 수집·처리·결과가 반복 실행되고 사용자 인터페이스와 오류 처리를 제공한다.
2. 예: 목포의 예비 카페 창업자가 인구·경쟁·접근성 데이터를 근거로 비교할 행정동 세 곳을 선택하도록 돕는다.
3. 기능은 업종 선택·추천 순위 표시 등 행동이고, 품질은 동일 입력의 동일 결과·출처 표시·오류 처리 등 수행 조건이다.
4. 키가 공개되면 제3자가 할당량과 비용을 사용할 수 있다. 파일 삭제뿐 아니라 키 폐기·재발급과 Git 기록 점검이 필요하다.
5. 실행, 검증, 문서, 리뷰, 오류 처리 등 측정 가능한 완료 조건이 포함되어야 한다.
