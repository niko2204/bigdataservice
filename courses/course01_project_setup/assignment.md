# 실습 과제: 프로젝트 제안과 실행환경

## 수행

1. 프로젝트 제안서 양식에 사용자, 상황, 데이터와 의사결정을 한 문장으로 작성한다.
2. 필수 기능 3~5개와 품질 요구사항 3개를 구분한다.
3. 공식 데이터 후보 3종의 URL, 제공필드, 기준시점과 이용조건을 조사한다.
4. 저장소를 실행하고 여섯 화면의 캡처와 실행환경 버전을 기록한다.
5. 팀 역할, 브랜치 규칙과 Definition of Done을 정한다.

## 제출·평가

제안서, 실행 화면, 첫 Pull Request 링크를 제출한다. 문제 명확성 30%, 데이터 가능성 25%, 범위 20%, 실행 성공 15%, 협업 규칙 10%로 평가한다.
