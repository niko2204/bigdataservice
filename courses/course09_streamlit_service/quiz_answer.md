# 확인 문제 해설

1. 순차 Python 코드로 UI를 쉽게 만들지만 위젯마다 전체가 재실행되어 느린 작업과 상태 관리가 필요하다.
2. cache_data는 반복 데이터 계산, session_state는 같은 사용자 세션에서 유지할 상호작용 상태에 사용한다.
3. 오류 대신 조건을 완화하라는 안내를 표시하고 이후 계산을 중단한다.
4. 지표별 정규화 점수, 가중치, 장점·약점, 데이터 출처·기준일과 한계를 표시한다.
5. 어떤 조건으로 결과가 만들어졌는지 재현하고 비교하기 위해서다.
6. 수행 시간, 망설임, 잘못된 클릭, 질문, 실패 지점과 사용자 발화를 기록한다.
