# 실습 과제: Streamlit 프로토타입

## 수행

1. 핵심 질문이 다른 페이지를 최소 3개 구현한다.
2. 필터 2개, 차트 3개, 지도 1개와 조건이 포함된 다운로드를 제공한다.
3. 데이터 로딩을 캐시하고 추천 로직을 화면 코드와 분리한다.
4. 빈 결과, 잘못된 입력과 파일 누락 오류를 처리한다.
5. 사용자 2명에게 과업을 주고 시간·실패·발화를 기록해 개선한다.

## 제출·평가

실행 코드, 화면 영상과 사용자 테스트표를 제출한다. 기능 25%, 데이터 정확성 25%, 오류 처리 15%, 사용성 20%, 코드 구조 15%다.
