# 최종 프로젝트 · 임베딩 기반 데이터 서비스

검색, 추천, 문서 분류, RAG, 텍스트-이미지 검색 중 하나를 선택한다.

## 제출물

1. 문제정의서와 데이터 카드
2. 실행 가능한 Jupyter Notebook
3. 기준선과 임베딩 모델 비교표
4. 오류·편향 분석표
5. 모델 카드
6. 10분 발표와 서비스 시연

## 통과 조건

- 타인이 새 환경에서 Notebook을 순서대로 실행할 수 있어야 한다.
- 모델 성능을 수치로 평가하고 기준선과 비교해야 한다.
- 최소 10개의 실패 사례를 유형화해야 한다.
- 개별 구술에서 임의의 코드 변경과 결과 변화를 설명해야 한다.
