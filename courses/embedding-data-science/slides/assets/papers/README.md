# 강의용 논문 도판 출처

Marp 강의안에 인용한 대표 도판의 출처와 원문 위치입니다. 파일명은 강의에서 설명하기
쉽도록 바꿨으며, 도판 내용은 임의로 수정하지 않았습니다. SVG·PNG 원본은 Marp 호환성과
저장소 용량을 고려해 고품질 WebP로 래스터화·압축했습니다.

각 도판의 저작권과 재배포 조건은 해당 논문·출판사의 라이선스를 따릅니다. 이 저장소의
강의안에는 교육 목적의 설명·비평과 정확한 출처를 함께 제공합니다.
