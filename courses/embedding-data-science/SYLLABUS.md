# 강의계획서: 임베딩 기반 데이터 과학

## 교과목 개요

텍스트·이미지·사용자·문서를 벡터 공간에 표현하고 유사도, 분류, 군집, 검색, 추천,
RAG에 활용하는 과정을 학습한다. 사전학습 모델 호출에 그치지 않고 벡터 수학, 기준선,
검색 평가, 오류 분석과 서비스 설계를 통합한다.

- 대상: 컴퓨터학부 4학년
- 기간: 10주, 주당 3시간
- 선수지식: Python, NumPy/Pandas 기초, 기초 확률·선형대수
- 도구: Jupyter/Colab, scikit-learn, 선택적으로 PyTorch·Transformers

|주|주제|필수 산출물|
|---:|---|---|
|1|벡터 표현과 임베딩|거리·유사도 비교표|
|2|토큰화와 TF-IDF|희소 검색 기준선|
|3|단어 임베딩|PPMI-SVD 실험|
|4|문맥 임베딩과 Transformer|Attention 계산 및 해석|
|5|문장·문서 임베딩|문장 검색 비교|
|6|분류·군집·시각화|분류/군집 오류 분석|
|7|임베딩 평가|P@K·R@K·MRR·nDCG 보고서|
|8|벡터 검색과 RAG|근거 표시 검색/RAG 골격|
|9|멀티모달 임베딩|텍스트-이미지 검색 실험|
|10|종합 프로젝트|Notebook·모델 카드·시연|

코드 설명, 디버깅, 시각화 대안과 문장 교정에 사용할 수 있다. 학생은 프롬프트,
AI 답변의 핵심, 채택·거부 이유, 실행 검증 결과를 제출해야 한다. 실행되지 않는 코드,
