# 공통 평가 루브릭

이 루브릭은 주차별 Notebook, 과제와 최종 프로젝트에 공통으로 적용하는 상위 기준이다.
과제별 세부 배점은 각 `assignments/*.md`를, 이론 시험의 문항별 부분점수는
`exams/instructor/`의 교수자용 루브릭을 따른다.

|영역|우수|보통|미흡|배점|
|---|---|---|---|---:|
|문제정의|사용자·의사결정·오류비용이 구체적|분석 목표만 제시|목표가 모호함|15|
|데이터|출처·라이선스·품질·분할을 기록|출처와 전처리 일부 기록|출처 또는 분할이 없음|15|
|기준선|단순 기준선과 동일 조건 비교|기준선 있으나 조건이 다름|기준선 없음|10|
|임베딩 방법|표현·차원·유사도·모델 선택 근거 설명|모델과 차원만 기록|모델 이름만 제시|15|
|평가|복수 지표와 질의별 분석|평균 지표만 제시|주관적 예시만 제시|15|
|오류·편향|실패 사례를 유형화하고 개선 검증|실패 사례만 나열|성공 사례만 제시|15|
|재현성|seed·버전·실행순서·비밀정보 관리|대부분 재실행 가능|실행 불가 또는 키 노출|10|
|설명·구술|코드 변경과 결과를 즉시 설명|주요 흐름 설명|자신의 결과를 설명 못함|5|

총점 100점. 생성형 AI 사용 여부 자체는 감점하지 않지만 사용·검증 기록이 없거나
구술 설명을 통과하지 못하면 해당 영역을 평가하지 않는다.
