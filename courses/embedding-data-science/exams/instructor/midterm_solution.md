## 문제 1 — 15점

### 1.1 — 6점

- 표현(1.5): 대상을 계산 가능한 형식으로 바꾼 결과 또는 방식.
- 임베딩(1.5): 대상 사이의 과업 관련 관계를 유한차원 벡터 공간에 보존하려는 함수/출력.
- 잠재공간(1.5): 관측 변수가 아니라 학습으로 형성된 내부 좌표 공간.
- 차이(1.5): 모든 표현이 학습된 벡터는 아니며, 임베딩의 좌표 공간이 잠재공간이 될 수
  있지만 세 용어의 범위와 초점이 다름.

### 1.2 — 4점

각 항목 1점.

1. TF–IDF: 희소, 정적에 가까움, 문서당 단일 벡터.
2. Word2Vec: 밀집, 정적, 단어당 단일 벡터.
3. BERT token state: 밀집, 문맥적, 문장당 다중 토큰 벡터.
4. late interaction: 밀집, 문맥적, 문서당 다중 벡터.

### 1.3 — 5점

타당한 항목 1점씩, 최대 5점: 같은 데이터/split, 같은 과업, 같은 평가 지표, 같은 검색
조건, 모델 학습 데이터·목표, 유사도·정규화, latency/memory, 통계적 불확실성, 오류 유형.

## 문제 2 — 20점

### 2.1 — 8점

각 2점. 식 1점, 값 1점.

$$\|x\|_2=\sqrt{1+4+4}=3$$

$$\|y\|_2=\sqrt{4+0+1}=\sqrt5$$

$$x^Ty=1\cdot2+2\cdot0+2\cdot1=4$$

$$\cos(x,y)=\frac{4}{3\sqrt5}$$

$$\|x-y\|_2=\sqrt{(-1)^2+2^2+1^2}=\sqrt6$$

두 norm을 한 소문항으로 보아 각각 1점씩 부여한다.

### 2.2 — 7점

전개 3점:

$$
\|\hat a-\hat b\|^2=(\hat a-\hat b)^T(\hat a-\hat b)
=\|\hat a\|^2+\|\hat b\|^2-2\hat a^T\hat b
=2-2\cos(a,b)
$$

- 단위 벡터의 norm이 1임: 1점
- 내적이 cosine과 같음: 1점
- cosine이 커질수록 제곱거리가 단조 감소하므로 순위 동일: 2점

### 2.3 — 5점

- 내적: $q^Ta=2$, $q^Tb=1$, 따라서 $a>b$ (1.5)
- cosine: $\cos(q,a)=1/\sqrt2$, $\cos(q,b)=1$, 따라서 $b>a$ (1.5)
- 내적은 방향 정렬과 크기를 함께 반영하지만 cosine은 방향만 비교함 (2)

## 문제 3 — 20점

### 3.1 — 7점

- 장학금: $df=3$, $idf=\ln(5/4)\approx0.223$ (1.5)
- 신청: $df=2$, $idf=\ln(5/3)\approx0.511$ (1.5)
- 기간: $df=1$, $idf=\ln(5/2)\approx0.916$ (1.5)
- `기간`은 corpus에서 드물고 D4에만 있어 D4를 구별하는 가중치가 큼 (2.5)

### 3.2 — 5점

- lexical gap 설명: `나누어 낼`과 `분할납부`가 동일 토큰을 공유하지 않음 (2)
- 대안 두 개, 각 1점: 형태소/사용자 사전, character n-gram, 동의어 확장, dense/hybrid.
- 부작용 1점: 분석기 의존, 차원·오탐 증가, 사전 유지비, 의미 과일반화 등.

### 3.3 — 5점

- TF saturation: 빈도가 증가해도 기여가 선형 증가하지 않음 (1.5) + 반복 키워드 문서 예 (1)
- length normalization: 긴 문서의 우연한 출현을 보정 (1.5) + 긴 보고서 예 (1)

### 3.4 — 3점

- 장점 1점: 고유 식별자/실제 희귀명과 일치할 때.
- 위험 1점: 오타끼리 우연히 일치하거나 noise가 과대평가.
- 완화 1점: min_df, 철자 정규화, 사용자 사전, hybrid 등.

## 문제 4 — 15점

### 4.1 — 6점

$$PMI=\log_2\frac{0.10}{0.20\times0.25}=\log_2 2=1$$

따라서 PPMI=1. $P(w,c)=0.01$이면

$$PMI=\log_2(0.01/0.05)=\log_2 0.2\approx-2.322$$

따라서 PPMI=0.

- 첫 PMI 식·값 2점, 첫 PPMI 1점
- 두 번째 PMI 식·부호 2점, 두 번째 PPMI 1점

### 4.2 — 5점

- CBOW: 주변 문맥으로 중심 단어 예측 (1.5)
- Skip-gram: 중심 단어로 주변 단어 예측 (1.5)
- 작은 corpus/희귀 단어에서는 각 중심 단어가 여러 문맥 예제를 만드는 Skip-gram이
  상대적으로 유리할 수 있음 (2). 단, 구현·sampling에 따라 다르다는 조건을 적어도 정답.

### 4.3 — 4점

- 예: 배가 달다 / 배가 아프다 / 배가 항구에 들어온다 (1.5)
- Word2Vec은 type당 하나의 벡터를 학습해 문맥 분포를 혼합 (1.5)
- 문맥 모델은 문장 전체를 조건으로 token별 hidden state를 생성 (1)

## 문제 5 — 15점

### 5.1 — 8점

scaled score:

$$[qk_1,qk_2,qk_3]/\sqrt2=[1,0,1]/\sqrt2=[0.707,0,0.707]$$

- score 2점
- softmax 분모 $2.028+1+2.028=5.056$ (1점)
- weight $[0.401,0.198,0.401]$ (2점)
- output:

$$0.401(1,0)+0.198(0,2)+0.401(1,1)=(0.802,0.797)$$

  계산 3점. 반올림 오차 허용.

### 5.2 — 4점

타당한 이유 각 2점, 두 개:

- weight는 value mixing 계수이지 최종 출력에 대한 인과효과와 동일하지 않음.
- multi-head, residual, MLP, 후속 layer가 영향을 바꿈.
- attention 재분배와 동일 예측이 가능할 수 있음.
- 상관적 시각화이며 반사실적 개입이 아님.

### 5.3 — 3점

- padding이 많을수록 평균이 pad vector 쪽으로 편향, 짧은 문장 영향 큼 (1.5)
- mask가 1인 실제 token만 합산하고 mask 합으로 나눔 (1.5)

## 문제 6 — 15점

### 6.1 — 6점

- bi-encoder: 문장을 독립 인코딩, 후보 벡터 사전 계산 가능 (1.5)
- cross-encoder: 문장 쌍을 함께 인코딩, token-level 상호작용 (1.5)
- bi는 빠르고 대규모 후보 검색에 적합, cross는 느리지만 정밀한 pair score (2)
- 100만 문서 1단계는 bi-encoder, 후보를 미리 인코딩하고 ANN/벡터 검색 가능 (1)

### 6.2 — 5점

- batch의 다른 정답 문서를 negative로 재사용해 양성을 상대적으로 높임 (2)
- 낮은 temperature는 분포를 날카롭게, gradient/구분 압력을 키우나 불안정 가능 (1.5)
- false negative는 실제 관련 문서를 밀어내 잘못된 학습 신호를 만듦 (1.5)

### 6.3 — 4점

- 문제 두 가지 각 1점: 표본 3개, qrels 없음, cherry-picking, 동일 조건 아님, 평균/실패 없음.
- 최소 평가: 여러 질의와 관련 문서 정답, 같은 corpus/split (1)
- P@k/Recall@k/MRR/nDCG 등 순위 지표와 질의별 오류 (1)
