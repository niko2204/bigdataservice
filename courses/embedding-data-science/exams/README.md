# 이론 중심 중간·기말고사

이 디렉터리는 임베딩 기반 데이터 과학 10주 과정의 이론 이해를 검증하는 시험 자료다.
프로그래밍 속도보다 **정의, 수식, 비교, 반례, 오류 진단, 평가 설계**를 측정한다.

|시험|범위|시간|배점|학생용|교수자용|
|---|---|---:|---:|---|---|
|중간고사|1–5주차|100분|100점|[문제지](midterm_exam.md)|[모범답안·루브릭](instructor/midterm_solution.md)|
|기말고사|6–10주차, 핵심 개념 누적|100분|100점|[문제지](final_exam.md)|[모범답안·루브릭](instructor/final_solution.md)|

## 출제 원칙

- 약 70–80%는 정의·이유·비교·오류 분석 등 이론 서술 문제다.
- 약 20–30%는 벡터, attention, 검색 지표의 작은 손계산 문제다.
- 외운 모델 순위나 제품명을 묻지 않고, 새로운 상황에 개념을 적용하게 한다.
- 계산 문제는 필요한 공식과 근삿값을 제공해 산술 속도보다 개념을 평가한다.
- 부분점수 기준을 먼저 정하고, 같은 논리의 답에는 같은 점수를 준다.

## 기본 시험 규칙

- 기본안은 폐쇄형 시험이며, 문제지에 제공된 공식만 사용할 수 있다.
- 단순 계산기 사용 여부는 교수자가 시험 전에 공지한다.
- 휴대전화, 인터넷, 생성형 AI, Notebook 실행은 허용하지 않는 것을 기본으로 한다.
- 모든 계산은 중간 과정을 남긴다. 답만 맞고 근거가 없으면 완전한 점수를 받지 못한다.
- 기호를 다르게 사용해도 정의와 논리가 맞으면 정답으로 인정한다.

## 공개 저장소 주의

`instructor/`에는 모범답안과 세부 부분점수 기준이 있다. 학생에게 저장소를 공개할 때는 다음
중 하나를 적용한다.

1. 실제 시험 전 `instructor/`를 비공개 LMS 또는 교수자 전용 저장소로 이동한다.
2. 이 문제를 연습문제로 공개하고 수치·사례·보기 순서를 바꾼 새 시험을 출제한다.
3. 모범답안에서 제공한 **변형 출제 지침**을 이용해 A/B형을 만든다.

공개된 문제와 답을 그대로 실제 성적평가에 사용하지 않는다.

## 권장 채점 절차

1. 답안을 보기 전에 모범답안의 핵심 요소와 부분점수 단위를 확정한다.
2. 한 문항은 가능하면 같은 채점자가 전체 학생을 채점한다.
3. 처음 5개 답안으로 예상하지 못한 타당한 풀이를 확인하고 루브릭을 보정한다.
4. 최종 점수와 함께 어떤 개념을 놓쳤는지 문항별 피드백 코드를 남긴다.
5. 재검토 요청은 “점수를 올려 달라”가 아니라 루브릭의 어느 요소가 충족됐는지 근거를
   제시하게 한다.
