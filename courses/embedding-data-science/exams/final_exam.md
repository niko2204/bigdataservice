나머지 방법만으로는 목적을 완전히 달성하기 어려운 이유를 쓰라.

1. 새 민원 문서를 이미 정의된 8개 업무 부서 중 하나로 배정
2. 라벨이 없는 학생 상담 기록에서 반복되는 주제 구조 탐색
3. 768차원 임베딩의 국소 이웃을 사람이 볼 수 있게 2차원으로 표시

외부/과업 평가의 차이를 설명하고, 사람이 수행할 수 있는 topic 품질 평가 한 가지를
제안하라.

## 문제 2 · 검색 평가 지표와 실험 누수 — 20점

한 질의의 상위 5개 문서 relevance가 다음과 같다.

$$[2,0,1,0,2]$$

전체 corpus에서 relevance가 1 이상인 문서는 4개다. 위 순위에 나타나지 않은 나머지 관련
문서 1개의 relevance는 1이다. binary 지표에서는 `rel >= 1`을 관련 문서로 본다.

### 2.1 계산 — 12점

다음을 계산하라.

1. Precision@5
2. Recall@5
3. reciprocal rank
4. DCG@5, IDCG@5, nDCG@5

다음을 사용한다.

$$
DCG@k=\sum_{i=1}^{k}\frac{2^{rel_i}-1}{\log_2(i+1)}
$$

$$
\log_2 2=1,\quad \log_2 3\approx1.585,\quad \log_2 4=2,
\quad \log_2 5\approx2.322,\quad \log_2 6\approx2.585
$$

### 2.2 지표 선택 — 4점

다음 서비스에서 우선할 지표 하나를 선택하고 이유를 쓰라. 다른 지표도 함께 봐야 한다면
그 이유를 덧붙여라.

1. 사용자가 상위 결과 하나만 클릭하는 FAQ 검색
2. 관련 판례를 빠짐없이 검토해야 하는 법률 조사

### 2.3 평가 누수 — 4점

학생이 20개 test 질의에서 가장 높은 nDCG를 얻는 embedding model과 threshold를 선택한 뒤
같은 20개 질의의 점수를 최종 성능으로 보고했다. 무엇이 잘못됐고 어떻게 고쳐야 하는가?

## 문제 3 · ANN 검색과 RAG 오류 분해 — 20점

### 3.1 정확 검색과 근사 검색 — 6점

exact nearest-neighbor search와 approximate nearest-neighbor(ANN) search를 정확도, 시간,
메모리, 데이터 규모 관점에서 비교하라. ANN에서 `Recall@k`를 따로 측정해야 하는 이유도
쓰라.

### 3.2 HNSW형 인덱스의 trade-off — 4점

검색 시 탐색 후보 수를 늘렸더니 ANN Recall@10은 0.88에서 0.97로 증가하고 p95 latency는
20ms에서 75ms로 증가했다. “무조건 0.97 설정이 더 좋다”고 할 수 없는 이유와 설정 선택에
필요한 서비스 정보를 두 가지 쓰라.

### 3.3 RAG 오류 단계 — 6점

각 사례의 **최초 실패 단계**를 `분할`, `검색`, `생성`, `인용` 중 하나로 분류하고 이유를
한 문장으로 쓰라.

1. 답이 원문의 두 문장에 걸쳐 있는데 두 문장이 서로 다른 chunk로 나뉘고 어느 chunk도
   완전한 조건을 담지 못했다.
2. 정답 chunk가 top-3에 있었지만 모델이 날짜 `8월 28일`을 `8월 18일`로 답했다.
3. 정답 문서는 corpus에 있지만 top-5에 나타나지 않았다.
4. 답변 내용은 맞지만 표시한 `[C17]`에는 해당 근거가 없다.

### 3.4 top-k — 4점

RAG에서 top-k를 늘릴 때 retrieval recall은 보통 증가할 수 있지만 최종 답변 품질은 떨어질
수 있다. 그 이유를 context noise, 비용, position 또는 충돌 근거 중 두 개 이상으로 설명하라.

## 문제 4 · 근거성, 인용과 거부 — 15점

30개 질문을 평가했다.

- answerable 질문 20개: 16개는 올바르게 답했고 4개는 잘못 거부했다.
- unanswerable 질문 10개: 8개는 올바르게 거부했고 2개는 근거 없이 답했다.

### 4.1 계산 — 5점

1. 올바른 시스템 행동을 `answerable에는 답함`, `unanswerable에는 거부함`으로 정의할 때
   전체 행동 정확도를 계산하라.
2. 전체 질문을 분모로 한 unsupported answer rate를 계산하라.

### 4.2 threshold 변화 — 4점

거부 threshold를 높일 때 false refusal과 unsupported answer가 일반적으로 어떻게 변하는지
설명하라. 의료·법률처럼 오류비용이 큰 서비스에서 threshold를 정할 때 정확도 외에 필요한
판단을 쓰라.

### 4.3 정답과 근거의 분리 — 3점

모델이 사전지식으로 우연히 정답을 말했지만 인용한 문서에는 근거가 없다. answer
correctness와 groundedness를 왜 별도 지표로 평가해야 하는지 설명하라.

### 4.4 LLM judge — 3점

LLM judge 하나의 점수만으로 RAG 정답성과 근거성을 평가할 때 생길 수 있는 문제를 두 가지
쓰고, 사람 평가와 함께 사용하는 검증 방법을 제안하라.

## 문제 5 · 멀티모달과 다중 벡터 임베딩 — 15점

### 5.1 CLIP형 대조학습 — 6점

같은 batch의 이미지–텍스트 쌍을 양성으로, 다른 조합을 음성으로 사용하는 학습을 설명하라.
이 방식이 별도 분류기 재학습 없이 zero-shot image classification에 사용되는 과정을 쓰라.

### 5.2 한국어 prompt 평가 — 4점

영어 중심으로 학습된 이미지–텍스트 모델을 한국어 관광 이미지 검색에 적용하려 한다.
공정한 평가를 위해 어떤 비교 조건과 질의 slice를 만들어야 하는지 세 가지 이상 쓰라.

### 5.3 단일 벡터와 late interaction — 5점

문서 이미지 전체를 한 벡터로 표현하는 방식과 token–patch 다중 벡터 late interaction을
비교하라. 표 안의 작은 단어를 찾는 질의에서 후자가 유리할 수 있는 이유와, 계산·저장
측면의 비용을 설명하라.

## 문제 6 · 표현 선택, 재현성과 서비스 판단 — 15점

### 6.1 Matryoshka 표현 — 5점

Matryoshka Representation Learning의 핵심 아이디어를 설명하라. 단순히 768차원 벡터의
앞 128차원을 잘라 쓰는 것과 무엇이 다르며, coarse-to-fine 검색에 어떻게 사용할 수 있는가?

### 6.2 재현성 진단 — 5점

다음 보고만으로 모델 A가 모델 B보다 우수하다는 결과를 재현할 수 없는 이유를 다섯 가지
이상 쓰라.

> “최신 embedding model A가 우리 데이터에서 MRR 0.82를 얻었고 B는 0.76이었다.”

### 6.3 운영 중 변화 — 5점

배포 6개월 후 새 정책명·새 학과명 질의의 실패가 증가했다. 이것을 단순한 모델 버그로
단정하면 안 되는 이유를 설명하고, 데이터 drift를 확인할 지표 두 개와 대응 실험 두 개를
제안하라.
