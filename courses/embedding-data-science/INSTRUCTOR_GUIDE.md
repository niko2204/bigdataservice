# 교수자 가이드

## 매주 3시간 운영안

1. 사전 질문과 개념 지도 20분
2. 이론 설명 25분
3. 작은 수학 예제 25분
4. 교수 시연 20분
5. 학생 개별 Notebook 실습 60분
6. 데이터 교체·오류 사례 만들기 30분
7. 결과 공유와 형성평가 20분

## 시연 원칙

- 실행 전에 학생이 결과를 예측하게 한다.
- 입력, 출력 차원, 모델 이름, 유사도 함수와 seed를 화면에 표시한다.
- 최신 모델과 TF-IDF 기준선을 같은 평가 데이터에서 비교한다.
- 모델 다운로드가 실패하면 수업이 중단되지 않도록 기본 셀을 먼저 진행한다.
- API 키를 Notebook에 직접 입력하거나 저장소에 올리지 않는다.

## 학생의 AI 대행 제출 방지

- 학생별로 질의 세 개와 문서 세 개를 수업 중 무작위 배정한다.
- 제출 후 한 셀의 거리 함수, 청크 크기 또는 평가 k를 변경하게 한다.
- 결과가 바뀌는 방향을 코드 실행 전에 설명하게 한다.
- 성공 사례보다 실패 사례의 원인 설명에 높은 점수를 준다.
- Notebook 끝의 AI 사용 기록과 Git/Colab 수정 기록을 함께 확인한다.

## 주차별 구술 질문

1. 유클리드 거리와 코사인 유사도의 결론이 다른 예를 설명하라.
2. TF-IDF가 의미 검색보다 유리한 질의는 무엇인가?
3. 말뭉치 크기와 윈도 크기가 단어 임베딩을 어떻게 바꾸는가?
4. 동일한 단어가 문장마다 다른 벡터를 갖는 이유는 무엇인가?
5. Bi-encoder와 Cross-encoder의 속도 차이는 어디서 발생하는가?
6. 군집 번호 자체에는 의미가 없다는 말은 무엇인가?
7. Recall@K와 Precision@K 중 서비스에 더 중요한 지표를 선택하라.
8. RAG 답변 오류가 검색과 생성 중 어느 단계인지 어떻게 구분하는가?
9. CLIP의 한국어 프롬프트 성능을 어떻게 공정하게 평가하는가?
10. 기준선보다 개선되었다는 주장을 뒷받침하는 증거는 무엇인가?

## 모델 선택 권장

수업 자료는 특정 모델에 종속되지 않는다. 다국어 문장 임베딩의 기본 예시는
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, 문맥 임베딩 선택 예시는
`klue/bert-base`, 멀티모달 선택 예시는 `openai/clip-vit-base-patch32`를 사용한다.
학기 시작 전에 모델 접근 가능 여부와 라이선스·모델 카드를 다시 확인한다.
