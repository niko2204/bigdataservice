## 변경 사항

이 디렉터리의 파일은 원본 Notebook을 한글로 직역한 것이 아니라 다음과 같이 변경한
파생 교육자료이다.

- 원본 12장 구성을 임베딩 중심 10주 과정으로 재배열
- 한국어 정책·관광·복지·창업 예제 데이터 추가
- 벡터 수학, TF-IDF, PPMI-SVD와 검색 평가 지표 보완
- API 키와 대규모 모델 없이 실행되는 기준선 코드 추가
- 문맥 임베딩, Sentence Transformers, CLIP을 선택 실습으로 분리
- 학생 활동, 형성평가, 오류 분석, 생성형 AI 사용 기록 추가
- 교수자 가이드, 과제와 루브릭 추가
- 용어·정의·수식·논문 도판·2024–2026 동향을 포함한 Marp 슬라이드 10개 추가
- 과정과 직접 관련된 원본 2·3·4·5·8·9·10장 Notebook을
  `upstream-handsonllm/`에 라이선스와 함께 선택 보관

Apache 2.0 제4조에 따라 원본 라이선스와 저작권 고지를 유지하고, 수정된 파일임을
명시한다. Marp 슬라이드의 논문 도판은 원문 서버를 직접 참조하고 캡션·출처 링크를
표시한다. `upstream-handsonllm/`의 원본 Notebook은 변경하지 않은 선택본이며 별도의
`LICENSE`와 원본 README를 유지한다.
