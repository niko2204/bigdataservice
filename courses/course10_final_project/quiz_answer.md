# 최종 확인 해설

1. 단위 테스트는 함수, 데이터 테스트는 품질 규칙, 통합 테스트는 단계 연결, 사용자 테스트는 실제 과업 수행을 확인한다.
2. Python·패키지 버전, 실행 위치와 파일 경로, 환경변수·인증키를 먼저 확인한다.
3. 가중치 민감도, 전처리 대안, 시간·표본 안정성, 설명가능성, 사용자 유용성과 전문가 검토를 사용한다.
4. 사용자가 결과 생성 조건을 검증하고 과도한 확신을 피하며 재현할 수 있게 하기 위해서다.
5. 예: 업종과 중요도를 입력해 후보지 3개와 근거를 3분 안에 찾고 그중 하나를 비교표로 설명한다.
6. 팀 결과는 일부 구성원의 작업이나 외부 도구로 완성될 수 있으므로 모든 학생의 처리·설명·수정 능력을 확인해야 한다.
