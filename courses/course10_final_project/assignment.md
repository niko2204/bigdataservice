# 최종 제출: 통합 서비스와 개인 역량

## 팀 제출

1. 새 환경에서 실행 가능한 GitHub 저장소와 Streamlit 서비스
2. 데이터 출처·사전·전처리·모델 검증이 포함된 최종 보고서
3. 단위·데이터·통합 테스트 결과와 사용자 테스트 개선 기록
4. 10분 발표자료와 5분 이내 입력 변화 시연 영상
5. 추천 실패 조건, 윤리·개인정보와 실제 적용 전 추가 검증

## 개인 제출

Lab 07 실행 Notebook, 개인 회고, 기여 커밋·리뷰와 동료평가를 제출한다. 이후 3분 코드 설명과 5분 즉석 수정에 참여한다.

## 평가

최종 루브릭과 데이터 분석 실기 루브릭을 함께 적용한다. 팀 결과가 완성되어도 개인이 임의 셀을 설명·수정하지 못하면 개인 실기 점수를 받을 수 없다.
