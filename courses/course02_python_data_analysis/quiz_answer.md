# 확인 문제 해설

1. 관측 단위를 모르면 서로 다른 수준의 값을 잘못 집계하거나 병합할 수 있다.
2. 행을 행정동별로 나누고 점포 식별자의 고유 개수를 계산한 뒤 결과를 한 표로 결합한다.
3. size는 행 수, count는 결측이 아닌 값 수, nunique는 고유값 수를 센다.
4. 표본평균을 추정하면서 자유도 하나를 사용했기 때문에 n-1로 나누어 모집단분산의 편향을 보정한다.
5. NaN으로 두면 계산 불가를 명시하고, 별도 범주로 두면 시장 미형성 또는 경쟁 부재를 정책적으로 해석할 수 있다. 무조건 1을 더하면 지표 의미가 바뀐다.
6. z점수는 상대적 위치일 뿐 오류 여부를 말하지 않는다. 실제로 큰 성공 점포일 수 있으므로 생성 원인과 분석 영향을 확인해야 한다.
