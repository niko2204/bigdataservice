# 실습 과제: 추천 모델과 민감도

## 수행

1. 기준, 단위, 방향과 가중치 출처를 표로 작성한다.
2. 한 행의 Min-Max와 가중합을 손으로 계산해 코드와 비교한다.
3. 균형·유동중심·저비용 시나리오 상위 5개와 순위범위를 비교한다.
4. Lab 05 회귀 또는 Lab 06 군집을 수행하고 기준모델·평가지표를 보고한다.
5. 전처리·척도·가중치 변화의 민감도와 추가 데이터 3종을 제안한다.

## 제출·평가

Notebook, 지표 정의서와 결과표를 제출한다. 수학·구현 30%, 검증 25%, 민감도 20%, 설명가능성 15%, 한계 10%다.
