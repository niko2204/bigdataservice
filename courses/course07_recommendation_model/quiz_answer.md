# 확인 문제 해설

1. 모든 점수가 클수록 좋다는 같은 의미가 되어야 가중합을 해석할 수 있다.
2. 최솟값·최댓값이 분모와 모든 변환값을 결정하므로 극단값이나 새 범위가 전체 점수를 바꾼다.
3. 가중치는 사용자 선호·정책 가치판단이다. 출처·시나리오를 공개하고 민감도 분석을 한다.
4. MAE는 절대오차에 선형, RMSE는 제곱 후 평균하여 큰 오차에 더 민감하다.
5. 데이터 누수, 편향, 과적합, 외삽과 숨은 변수가 있을 수 있고 예측 관계는 원인 관계가 아니다.
6. 큰 단위 변수가 거리를 지배하지 않게 표준화하며 inertia, silhouette, 안정성과 해석 가능성을 함께 본다.
