# 실습 과제: 분석 데이터베이스

## 수행

1. 지역, 기준월 관측, 점포와 추천 실행 테이블의 관측 단위를 정의한다.
2. 기본키·외래키·CHECK가 포함된 ERD와 schema.sql을 작성한다.
3. CSV를 트랜잭션으로 적재하고 원본·DB 행 수를 비교한다.
4. 필터, GROUP BY, JOIN을 포함한 질의 3개를 작성한다.
5. Python 파라미터 질의와 반복 적재의 중복 방지를 검증한다.

## 제출·평가

ERD, 스키마, 적재 코드와 SQL 결과를 제출한다. 모델링 30%, 제약조건 20%, SQL 25%, Python 연동 15%, 재실행 10%다.
