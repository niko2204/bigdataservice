# 실습 과제: 전처리 대안과 데이터 통합

## 수행

1. 원본의 완전성·유일성·유효성 품질표를 만든다.
2. 결측 처리 두 방법과 IQR 1.5·3.0 결과를 비교한다.
3. 최종 처리 정책을 선택하고 전후 행 수·평균·중앙값·표준편차를 기록한다.
4. 점포 데이터를 행정동 단위로 사전 집계한다.
5. validate와 indicator를 사용해 인구 데이터와 1:1 병합하고 미매칭 키를 보고한다.

## 제출·평가

원본을 변경하지 않는 전처리 함수, 비교표와 통합 CSV를 제출한다. 진단 20%, 대안 비교 25%, 병합 검증 25%, 코드 재현성 20%, 근거 10%다.
