위도·경도, 좌표계, 거리, 반경, 밀집도 개념을 학습하고 Folium으로 상권 지도를 만든다. 위치정보의 정밀도와 개인정보 위험을 함께 검토한다.

`lecture_note.ipynb`의 좌표 검증, Haversine 거리와 원 면적 표현 셀을 순서대로 실행한다. 지도는 장식이 아니라 공간 분석 결과이므로 집계 단위와 경계 효과를 반드시 설명한다.
