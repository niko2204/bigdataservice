# 실습 과제: 공간 분석 지도

## 수행

1. 좌표계, 위도·경도 순서, 결측과 범위를 검증한다.
2. 유동인구가 원 면적에 비례하는 행정동 지도를 만든다.
3. 업종 필터, 범례, 단위와 상세 툴팁을 제공한다.
4. 기준 행정동에서 다른 지역까지 Haversine 거리표를 작성한다.
5. 직선거리, MAUP, 경계 효과와 개인정보 한계를 설명한다.

## 제출·평가

실행 가능한 Notebook·HTML 또는 Streamlit 화면을 제출한다. 좌표 정확성 25%, 표현 정확성 20%, 상호작용 20%, 거리 분석 15%, 한계·윤리 20%다.
