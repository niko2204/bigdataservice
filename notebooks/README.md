## 권장 학습 방법

1. 해당 Course의 lecture_note.ipynb를 열어 본문과 예제 셀을 학습한다.
2. Notebook을 복사하고 학번을 입력한다.
3. 완성 예제를 위에서부터 실행하며 중간값을 예상한다.
4. 코드를 한 줄씩 바꾸어 결과 변화를 확인한다.
5. TODO와 독립 연습을 수행한다.
6. 그래프마다 관찰·해석·한계를 작성한다.
7. Restart & Run All로 재현성을 확인한다.

완성 코드만 복사하면 학습이 끝난 것이 아니다. 결과의 단위, 가정, 처리 선택과 실패 조건을 말로 설명할 수 있어야 한다.
