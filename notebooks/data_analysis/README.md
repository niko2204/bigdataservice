# 데이터 분석 이론·수학·실습

각 노트북은 셀을 위에서부터 실행한다. STUDENT_ID에 본인 학번을 입력하면 다른 학생과 수치·결측·이상값 위치가 다른 데이터가 생성된다.

| 순서 | 노트북 | 핵심 역량 |
|---:|---|---|
| 00 | 수학과 NumPy | 벡터·평균·거리 |
| 01 | 데이터 품질 | 결측·중복·이상값 |
| 02 | 기술통계 | 분산·표준편차·z점수 |
| 03 | 표본과 신뢰구간 | 부트스트랩 |
| 04 | 가설검정과 상관 | t검정·효과크기 |
| 05 | 회귀분석 | 최소제곱·MAE·RMSE |
| 06 | 군집과 PCA | 표준화·K-means |
| 07 | 종합 실기평가 | 독립 분석·구두 확인 |
